4. CONFIGURAÇÃO DE WEBHOOKS
================================================================================

Webhooks são essenciais para sincronizar o Stripe com seu app automaticamente.

PASSO 1: Obter URL do Webhook do Supabase

Sua URL será no formato:
https://[SEU_PROJECT_REF].supabase.co/functions/v1/stripe-webhook

Substitua [SEU_PROJECT_REF] pelo ID do seu projeto Supabase
(encontrado em: Supabase Dashboard > Settings > API > Project URL)

Exemplo:
https://oprqgllsqtfdyjgvgovo.supabase.co/functions/v1/stripe-webhook

PASSO 2: Criar endpoint no Stripe

Dashboard > Desenvolvedores > Webhooks > + Adicionar endpoint

URL do endpoint: [Sua URL do Supabase]
Descrição: Vigil - Webhook de Assinaturas
Versão: Última disponível
Eventos a escutar: Selecione os seguintes eventos:

✓ checkout.session.completed
✓ customer.subscription.created
✓ customer.subscription.updated
✓ customer.subscription.deleted
✓ invoice.payment_succeeded
✓ invoice.payment_failed
✓ customer.subscription.trial_will_end

PASSO 3: Copiar o Signing Secret

Após criar o webhook, você verá:
Signing secret: whsec_xxxxxxxxxxxxxxxxxxxxxxxxxx

➜ COPIE ESTE VALOR (será STRIPE_WEBHOOK_SECRET)

5. VARIÁVEIS DE AMBIENTE (SUPABASE)
================================================================================

Você precisará adicionar 3 variáveis de ambiente no Supabase:

Supabase Dashboard > Project Settings > Edge Functions > Secrets

1. STRIPE_SECRET_KEY
   → Dashboard Stripe > Desenvolvedores > Chaves de API
   → Copie a "Secret key" (começa com sk_test_ ou sk_live_)
   → Valor: sk_test_xxxxxxxxxxxxxxxxxxxxxx (modo teste)
           sk_live_xxxxxxxxxxxxxxxxxxxxxx (modo produção)

2. STRIPE_WEBHOOK_SECRET
   → Valor copiado no passo 4.3 acima
   → Valor: whsec_xxxxxxxxxxxxxxxxxxxxxxxxxx

3. STRIPE_PUBLISHABLE_KEY (opcional, para frontend)
   → Dashboard Stripe > Desenvolvedores > Chaves de API
   → Copie a "Publishable key" (começa com pk_test_ ou pk_live_)
   → Valor: pk_test_xxxxxxxxxxxxxxxxxxxxxx

COMO ADICIONAR NO SUPABASE:
```
supabase secrets set STRIPE_SECRET_KEY=sk_test_xxxxxx
supabase secrets set STRIPE_WEBHOOK_SECRET=whsec_xxxxxx
supabase secrets set STRIPE_PUBLISHABLE_KEY=pk_test_xxxxxx
```

OU pela interface web:
Edge Functions > Manage Secrets > Add Secret

6. ATUALIZAÇÃO DOS IDs DE PREÇOS NO CÓDIGO
================================================================================

Você precisa atualizar o arquivo:
supabase/functions/create-checkout-session/index.ts

Substitua os IDs placeholder pelos IDs reais do Stripe:

const priceIds: Record<string, Record<string, string>> = {
  basic: {
    monthly: 'price_xxxxxxxx', // ← Substitua com o ID real
    annually: 'price_xxxxxxxx', // ← Substitua com o ID real
  },
  pro: {
    monthly: 'price_xxxxxxxx', // ← Substitua com o ID real
    annually: 'price_xxxxxxxx', // ← Substitua com o ID real
  },
  premium: {
    monthly: 'price_xxxxxxxx', // ← Substitua com o ID real
    annually: 'price_xxxxxxxx', // ← Substitua com o ID real
  },
};

Se você quiser usar preços promocionais, adicione uma lógica para verificar
a data atual e usar os IDs dos preços promocionais quando aplicável.

Exemplo com promoção:

const promotionActive = new Date() < new Date('2025-02-11');

const priceIds = promotionActive ? {
  basic: {
    monthly: 'price_basic_monthly_promo',
    annually: 'price_basic_annually',
  },
  pro: {
    monthly: 'price_pro_monthly_promo',
    annually: 'price_pro_annually',
  },
  premium: {
    monthly: 'price_premium_monthly_promo',
    annually: 'price_premium_annually',
  },
} : {
  basic: {
    monthly: 'price_basic_monthly',
    annually: 'price_basic_annually',
  },
  pro: {
    monthly: 'price_pro_monthly',
    annually: 'price_pro_annually',
  },
  premium: {
    monthly: 'price_premium_monthly',
    annually: 'price_premium_annually',

};

7. TESTES
================================================================================

MODO TESTE DO STRIPE:
Use os cartões de teste do Stripe para simular pagamentos:

Cartão aprovado:
  Número: 4242 4242 4242 4242
  Data: Qualquer data futura
  CVC: Qualquer 3 dígitos
  CEP: Qualquer

Cartão recusado:
  Número: 4000 0000 0000 0002

Cartão que requer autenticação 3D:
  Número: 4000 0025 0000 3155

TESTES ESSENCIAIS:

1. Teste de Checkout Básico
   → Criar uma sessão de checkout
   → Completar o pagamento
   → Verificar se o webhook atualizou o Supabase
   → Verificar se o plano do usuário foi atualizado

2. Teste de Período de Teste
   → Assinar o plano Pro (7 dias de teste)
   → Verificar se trial_ends_at foi preenchido
   → Verificar se status é 'trialing'

3. Teste de Cancelamento
   → Cancelar uma assinatura no Stripe Dashboard
   → Verificar se o webhook atualizou o status para 'canceled'
   → Verificar se o plano do usuário voltou para 'free'

4. Teste de Falha de Pagamento
   → Simular falha de pagamento
   → Verificar se o status foi atualizado para 'past_due'

5. Teste de Renovação
   → Simular renovação de assinatura
   → Verificar se current_period_end foi atualizado

LOGS E DEBUGGING:

Stripe Dashboard > Desenvolvedores > Eventos
→ Veja todos os eventos enviados e suas respostas

Stripe Dashboard > Desenvolvedores > Webhooks > [Seu webhook]
→ Veja tentativas de entrega e respostas

Supabase Dashboard > Logs > Edge Functions
→ Veja logs das suas functions

COMANDOS ÚTEIS
================================================================================

DEPLOY DAS EDGE FUNCTIONS:
```bash
# Fazer deploy de todas as functions
supabase functions deploy

# Fazer deploy de uma function específica
supabase functions deploy create-checkout-session
supabase functions deploy stripe-webhook
```

TESTAR LOCALMENTE:
```bash
# Executar function localmente
supabase functions serve create-checkout-session --env-file .env.local

# Testar webhook localmente (use Stripe CLI)
stripe listen --forward-to localhost:54321/functions/v1/stripe-webhook
```

VER LOGS:
```bash
supabase functions logs create-checkout-session
supabase functions logs stripe-webhook
```

NOTAS IMPORTANTES

1. SEGURANÇA:

   - Use HTTPS em produção

   - Configure impostos brasileiros se necessário
   - Stripe Tax pode calcular automaticamente

4. CONFORMIDADE:

   - Inclua termos de serviço e política de reembolso
