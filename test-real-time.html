🔄 Teste de Funcionalidades em Tempo Real - Vigil

Este arquivo ajuda a verificar se as correções nas funcionalidades em tempo real estão funcionando corretamente.

📋 Instruções Gerais:

  1. Certifique-se de que o servidor está rodando (npm run dev)
  2. Abra a aplicação em duas abas diferentes do navegador
  3. Faça login com contas diferentes em cada aba (ou use a mesma conta)
  4. Execute os testes abaixo em sequência

🔔 Teste 1: Sistema de Notificações

Como testar:

  1. Aba 1: Vá para a página de notificações
  2. Aba 2: Siga o usuário da Aba 1, curta um post, ou comente
  3. Aba 1: Verifique se a notificação aparece instantaneamente
  • Notificações aparecem instantaneamente
  • Contador de notificações atualiza em tempo real
  • Não há logs excessivos no console
  • Interface permanece responsiva

💬 Teste 2: Sistema de Mensagens

Como testar:

  1. Aba 1: Vá para a página de mensagens
  2. Aba 2: Vá para a página de mensagens
  3. Abra a mesma conversa nas duas abas
  4. Envie mensagens alternadamente em cada aba
  • Mensagens aparecem instantaneamente na outra aba
  • Contador de mensagens não lidas atualiza
  • Scroll automático funciona corretamente
  • Não há duplicação de mensagens
  • Status "Enviando..." funciona corretamente

👥 Teste 3: Sistema de Presença

Como testar:

  1. Aba 1: Observe os avatares com indicadores de status online
  2. Aba 2: Faça logout ou feche a aba
  3. Aba 1: Verifique se o status muda para offline
  • Indicadores de status online funcionam
  • Status atualiza quando usuário sai
  • Status atualiza quando usuário entra

⚡ Teste 4: Performance e Console

Como testar:

  1. Abra o DevTools (F12)
  2. Vá para a aba Console
  3. Navegue pela aplicação e use as funcionalidades
  4. Verifique se não há logs excessivos
  • Console limpo (sem logs desnecessários)
  • Aplicação responsiva
  • Sem erros de JavaScript
  • Conexões WebSocket estáveis
