1.2 - CORRIGIR USUÁRIOS COM TRIALS EXPIRADOS
───────────────────────────────────────────────────────────────────────────────

Execute no SQL Editor do Supabase:

-- Verificar trials expirados
SELECT 
  s.user_id,
  p.username,
  s.plan,
  s.status,
  s.trial_ends_at,
  p.plan as profile_plan,
  CASE 
    WHEN s.trial_ends_at < NOW() THEN 'EXPIRADO'
    ELSE 'ATIVO'
  END as trial_status
FROM subscriptions s
JOIN profiles p ON s.user_id = p.id
WHERE s.status = 'trialing';

-- Corrigir trials expirados (atualizar status e reverter plano)
UPDATE subscriptions 
SET status = 'expired', end_date = NOW()
WHERE status = 'trialing' 
  AND trial_ends_at < NOW();

UPDATE profiles 
SET plan = 'free'
WHERE id IN (
  SELECT user_id 
  FROM subscriptions 
  WHERE status = 'expired'
);

-- Enviar notificações para usuários afetados
INSERT INTO notifications (recipient_id, actor_id, type, metadata)
SELECT 
  s.user_id,
  NULL,
  'trial_expired',
  jsonb_build_object(
    'previous_plan', s.plan,
    'expired_at', NOW(),
    'message', 'Seu período de teste do plano ' || UPPER(s.plan) || ' expirou. Para continuar aproveitando os recursos premium, assine um plano.'
  )
FROM subscriptions s
WHERE s.status = 'expired' 
  AND s.trial_ends_at < NOW()
  AND NOT EXISTS (
    SELECT 1 FROM notifications n 
    WHERE n.recipient_id = s.user_id 
      AND n.type = 'trial_expired'
  );

3.2 - CRIAR CRON JOB PARA VERIFICAR EXPIRAÇÕES (DIÁRIO)
───────────────────────────────────────────────────────────────────────────────

Execute no SQL Editor:

-- Executar todo dia à meia-noite (00:00)
SELECT cron.schedule(
  'check-trial-expirations-daily',
  '0 0 * * *',
  $$
  SELECT net.http_post(
    url := 'https://oprqgllsqtfdyjgvgovo.supabase.co/functions/v1/check-trial-expirations',
    headers := '{"Authorization": "Bearer [SERVICE_ROLE_KEY]", "Content-Type": "application/json"}'::jsonb

  $$
);

IMPORTANTE: Substitua [SERVICE_ROLE_KEY] pela service role key do projeto.

5.1 - QUERIES ÚTEIS PARA MONITORAMENTO
───────────────────────────────────────────────────────────────────────────────

-- Ver todos os trials ativos
SELECT 
  p.username,
  s.plan,
  s.status,
  s.trial_ends_at,
  EXTRACT(DAY FROM (s.trial_ends_at - NOW())) as dias_restantes
FROM subscriptions s
JOIN profiles p ON s.user_id = p.id
WHERE s.status = 'trialing'
ORDER BY s.trial_ends_at;

-- Ver trials que expiram nos próximos 3 dias
SELECT 
  p.username,
  s.plan,
  s.trial_ends_at,
  EXTRACT(DAY FROM (s.trial_ends_at - NOW())) as dias_restantes
FROM subscriptions s
JOIN profiles p ON s.user_id = p.id
WHERE s.status = 'trialing'
  AND s.trial_ends_at BETWEEN NOW() AND NOW() + INTERVAL '3 days'
ORDER BY s.trial_ends_at;

-- Ver histórico de trials (incluindo expirados)
SELECT 
  p.username,
  s.plan,
  s.status,
  s.trial_ends_at,
  s.created_at,
  s.end_date
FROM subscriptions s
JOIN profiles p ON s.user_id = p.id
WHERE s.trial_ends_at IS NOT NULL
ORDER BY s.created_at DESC;

-- Ver notificações de trial enviadas
SELECT 
  p.username,
  n.type,
  n.metadata->>'message' as mensagem,
  n.created_at,
  n.is_read
FROM notifications n
JOIN profiles p ON n.recipient_id = p.id
WHERE n.type IN ('trial_expired', 'trial_expiring')
ORDER BY n.created_at DESC;

5.2 - PROBLEMAS COMUNS E SOLUÇÕES
───────────────────────────────────────────────────────────────────────────────

❌ PROBLEMA: Edge function não executa
✅ SOLUÇÃO: 
   - Verificar se foi feito deploy: supabase functions list
   - Verificar logs de erro no Dashboard
   - Testar manualmente com curl

❌ PROBLEMA: Cron job não está rodando
✅ SOLUÇÃO:
   - Verificar se pg_cron está instalado: SELECT * FROM pg_extension WHERE extname = 'pg_cron';
   - Verificar jobs ativos: SELECT * FROM cron.job;
   - Verificar histórico: SELECT * FROM cron.job_run_details ORDER BY start_time DESC LIMIT 10;

❌ PROBLEMA: Usuário não recebe notificação
✅ SOLUÇÃO:
   - Verificar se tipo 'trial_expired' foi adicionado à constraint
   - Verificar se edge function rodou com sucesso
   - Verificar tabela notifications: SELECT * FROM notifications WHERE type = 'trial_expired';

❌ PROBLEMA: Trial não ativa plano premium
✅ SOLUÇÃO:
   - Verificar se código atualizado foi deployado
   - Verificar se profiles.plan foi atualizado: SELECT plan FROM profiles WHERE id = '[USER_ID]';
   - Limpar cache do navegador e fazer refresh do usuário

6.1 - DASHBOARD DE TRIALS
───────────────────────────────────────────────────────────────────────────────

-- Taxa de conversão de trials
SELECT 
  COUNT(CASE WHEN status = 'trialing' THEN 1 END) as trials_ativos,
  COUNT(CASE WHEN status = 'expired' THEN 1 END) as trials_expirados,
  COUNT(CASE WHEN status = 'active' AND trial_ends_at IS NOT NULL THEN 1 END) as convertidos,
  ROUND(
    COUNT(CASE WHEN status = 'active' AND trial_ends_at IS NOT NULL THEN 1 END)::numeric / 
    NULLIF(COUNT(CASE WHEN trial_ends_at IS NOT NULL THEN 1 END), 0) * 100, 
    2
  ) as taxa_conversao_pct
FROM subscriptions;

-- Trials por plano
SELECT 
  plan,
  COUNT(*) as total,
  COUNT(CASE WHEN status = 'trialing' THEN 1 END) as ativos,
  COUNT(CASE WHEN status = 'expired' THEN 1 END) as expirados,
  COUNT(CASE WHEN status = 'active' THEN 1 END) as convertidos
FROM subscriptions
WHERE trial_ends_at IS NOT NULL
GROUP BY plan;
